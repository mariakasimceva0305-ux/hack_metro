Round 3 (AI/ML layer)
- Built the service side against the ML contract (`experiments/ml`) and made it degrade cleanly: each file is optional, the load never raises, and `/health.ml` shows what is loaded and any load errors. Tested on synthetic fixtures first, then the real files arrived (intervals, anomalies, hybrid, hybrid_folds, REPORT.md). `prepare_data.py` copies them (`--ml-dir`) and removes stale copies. A rerun changed nothing else in the bundle except meta.json.
- `app/ml.py`: intervals are stored as P10/P50 and P90/P50 ratios, so the band follows v08, the hybrid and dispatcher corrections alike. Overflow probability uses a two-piece lognormal through P10/P50/P90 (P10 = 0 falls back to the other side's σ). Also: REPORT.md table parser with the Russian «питч» section as the summary, Russian anomaly labels, hybrid cubes, and `hybrid_weight_zero` detection (prediction == base).
- Aggregation of the band: hours of a day and routes are summed as fully correlated, days of a month as independent. With full correlation across days the December band would have been −32 %/+38 %; now it is −6 %/+7 %.
- API: `p10`/`p90` + `interval` in forecast/series/stop, P10/P90 export columns, `model=v08|hybrid` on every forecast endpoint (`Adj.model`, and the baselines use the same model), `/fleet` `plan_by` + `p_overflow` + `overflow`, new `/anomalies`, `/model`, `/assistant`.
- UI: «80 % интервал» band (day and month), KPI «Вероятность переполнения», overflow line and «Планировать по P90» in the fleet panel, anomaly dots with tooltips on the month history chart, «ИИ-детектор аномалий» panel (kind filter, click opens the month, informational «Исключить аномалии из обучения»), «Модель» card (REPORT tables, sources with links, factors, «Гибрид ML» toggle + filter-bar switch), «Помощник диспетчера» (rule-based, no LLM).
