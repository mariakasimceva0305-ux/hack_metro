# Прогноз загрузки трамваев Москвы

Командный проект — победитель хакатона Московского транспорта. Почасовой прогноз посадок на 10 трамвайных маршрутах на ноябрь–декабрь 2025 года и сервис визуализации.


## Интерфейс

[Итоговый командный проект: MetroHack2026](https://github.com/Saykra1/MetroHack2026) — карта загрузки, прогноз по маршрутам и сценарии для диспетчеров.

![Интерфейс итогового командного проекта](https://raw.githubusercontent.com/Saykra1/MetroHack2026/main/service/docs/screenshots/ui2_overview_light_desktop.png)
## Модель

Прогноз складывается из уровня пассажиропотока по маршруту, почасового профиля, типа дня и календарных корректировок. Модель позволяет разложить прогноз на понятные множители. Финальный горизонт: 10 маршрутов × 61 день × 24 часа = 14 640 строк.

## Оценка качества

`python src/make_final.py --no-weather --name verified` пересчитывает прогноз по локальным агрегатам без замены будущих значений фактическими наблюдениями. Проверяются уникальность ключа маршрут–дата–час, отсутствие пропусков и неотрицательность.

WAPE-score базовой модели на исторических проверках: октябрь — 0,9044; 15 сентября–31 октября — 0,8955; февраль–март — 0,9048; апрель–май — 0,8470. Эти периоды использовались при разработке: повторный расчёт не превращает их в новый независимый test. Сценарные события также требуют проверки доступности информации на дату прогноза.

Результат командного решения на публичном лидерборде: **0,90167**. Исторические проверки ниже и конкурсная оценка используют разные выборки.

## Запуск

```text
pip install numpy pandas duckdb openpyxl statsmodels
python src/make_final.py --no-weather --name verified
cd service
pip install -r requirements-dev.txt
python -m pytest -q
uvicorn app.main:app --port 8000
```

Структура: `src/` — прогноз; `labels/` — агрегированные данные; `research/` — календарные факторы; `experiments/` — параметры; `service/` — API и интерфейс. Описание данных организаторов: [docs/DATASET_README.md](docs/DATASET_README.md).
